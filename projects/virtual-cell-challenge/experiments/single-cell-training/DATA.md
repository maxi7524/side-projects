## Unavailable inputs

- Original VCC/GEARS input dataset: not present in source repositories; supply the original dataset and run the preserved preprocessing cells.

Historical figures, reports and models: use `--include-artifacts`.

Committed reports and figures are already included; viewing them requires no data download. Their manifest retrieval URLs point to this collection rather than a retired source repository.
